# 学友打！（がくゆうだ！）⚡

学友会メンバーの顔・名前・所属をタイピング形式で楽しく覚えるWebアプリケーション。

![学友打](images/default_avatar.svg)

---

## 🌟 特徴 & 機能

1. **完全データ駆動型 (Google スプレッドシート & GAS 連携)**
   - 名簿CSVおよびスプレッドシートの更新とGoogle Driveへの写真追加だけで、ゲーム内容が自動拡張。
2. **柔軟なローマ字入力パーサー (Typing Engine)**
   - 「し（si / shi / ci）」「っ（促音）」「ん（撥音）」「しゃ（sya / sha / sixya等）」など、多様な打ち分けにリアルタイムで完全追従。
3. **記憶定着を促す復習システム**
   - ミス打鍵があったメンバーや5秒以上かかったメンバーを自動抽出し、リザルト画面で横スクロールカード表示。
4. **リッチなUI/UX & シンセ効果音**
   - Web Audio APIによるゼロ遅延シンセ効果音（打鍵音、ミス音、ファンファーレ）。
   - 残り時間10秒以下の鼓動（pulse）アニメーション、コンボフィーバー演出、ノーミスクリア時の+2秒時間回復ボーナス。
5. **部署対抗 & 個人ハイスコアランキング**
   - 部署選択と連動したスコア登録フォーム（LocalStorageで前回の入力内容を自動記憶）。

## 🚀 ローカル起動方法

ブラウザで直接 `index.html` を開くか、ローカルサーバーを起動してアクセスします。

```bash
# Python によるローカルサーバー起動例
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` を開きます。
